# Ruipeng LU · 盧瑞鵬

**English** · [繁體中文](#繁體中文)

PhD student in Gerontology at **Renmin University of China**.

I study adult children's marital relationships and intergenerational relations
using longitudinal survey data and latent-variable models. I also develop tools
for the research workflow: shared statistical sessions, evidence-traced writing,
native Word revision and coordination between coding agents.

## Research tools

| Project | Purpose |
| --- | --- |
| [Terminal multi-agent collaboration](https://github.com/lzhs1995/multi-agent-collaboration) | Codex and Claude Code handoffs in macOS terminals; cmux stable, Herdr in preview |
| [Thesis refiner](https://github.com/lzhs1995/thesis-refiner) | Evidence-traced revision of empirical manuscripts with local verification and NotebookLM review |
| [Academic Word revision](https://github.com/lzhs1995/officecli-word-revision) | Native Word revisions, thesis-format checks and Zotero field preservation |
| [CCC](https://github.com/lzhs1995/ccc) | Session continuation for agents in cmux and Herdr |
| [Stata Workbench](https://github.com/lzhs1995/stata-workbench-shared-session) | A visible Stata session shared by a person and agents |
| [RStudio agent workbench](https://github.com/lzhs1995/clauder-rstudio-workbench) | ClaudeR connections, descriptive tables and paired CMAverse mediation workflows |

**Stata family:** [runtime](https://github.com/lzhs1995/stata-workbench-shared-session)
· [operating skill](https://github.com/lzhs1995/stata-workbench-shared-session-skill)
· [Next preview](https://github.com/lzhs1995/stata-workbench-next).
